# guji-markdown v0.2 规范：古籍 Markdown 全文格式

> 状态：正式（v0.2）  
> 适用：全文数据仓（`book-text`）、版本导出、古籍网页渲染、排版引擎。

---

## 一、定位与设计原则

`guji-markdown` 是平台面向**全文存储与最终排印呈现（Level 3）**的标准。
它将古籍特有的排版现象映射为贴近 CommonMark 习惯的紧凑记号：
- 行首抬头 `^`（平抬）与挪抬 `.`（空格）；
- 双行夹注 `<a|b>` 与单行小注 `:jz[x]{type=单行}`；
- 校勘三式：改字 `[甲]{{乙}}`、删字 `{{乙}}`、补字 `((甲))`；
- 专名号 `/…/` 与书名号 `《…》`。

---

## 二、两大排版形态

在具体存储与输出时，全文提供两种排版形态：

### 1. 分行 Markdown（`*.lines.md`）
- **核心目的**：忠实反映底本分行排版。
- **排版规则**：
  - 底本一列对应输出文本中的一行；
  - 版心列、空列输出为空行（使“第 k 行”严格对应“第 k 列”）；
  - 行首保留 `^` 抬头与 `.` 挪抬记号；
  - 双行夹注保留 `|` 转行点标记（`<两江总督|采进本>`）；
  - 页面边界统一使用 HTML 注释 `<!-- pN -->` 标识。
- **示例**：
  ```markdown
  <!-- p3 -->
  欽定四庫全書總目卷四
  經部四
  ^易類四
  ^讀易私言一卷<兩江總督|採進本>
  ^元許衡撰衡字平仲河內人官至集賢殿大學士
  兼國子祭酒諡文正事迹具元史本傳其書論六
  爻之德位大㫖多發明繫詞傳同功異位柔危剛
  ```

### 2. 分段自然段 Markdown（`*.reflow.md` / `*.md`）
- **核心目的**：面向现代阅读体验的自然段连续文本。
- **排版规则**：
  - **自适应满列聚合**：统计整册满列阈值，非满列末端判定为自然段结束，其余各列自动消除换行拼接为长段落；
  - **消除小注转行**：双行夹注中的 `|` 自动去除（`<a|b>` $\rightarrow$ `<ab>`）；
  - **消除敬语断行**：取消行首 `^` 与 `.`，文本自然顺承；
  - **页码保留**：在段落文本中间保留 `<!-- pN -->` 锚点，既保证段落连续，又不丢失与原书影像的映射。
- **示例**：
  ```markdown
  <!-- p3 -->欽定四庫全書總目卷四

  經部四

  易類四

  讀易私言一卷<兩江總督採進本>

  元許衡撰。衡字平仲，河內人，官至集賢殿大學士兼國子祭酒，諡文正。事迹具《元史》本傳。其書論六爻之德位，大㫖多發明《繫詞傳》「同功異位，柔危剛勝」之義，而又類聚各卦畫之居於六位者分别觀之。葢健順動止，人說陷麗，其吉凶悔吝，又視乎所<!-- p4 -->値之時，而必以正且得中爲上。
  ```

## 三、字形三维度（正交衍生）

同一篇古籍 Markdown 文本，允许独立衍生出三种字形表现层：

1. **原刻字形（`original`）**：
   - 保留底本所有原样文字、刻本异体字（如 `𢰅`、`𠀉`、`宐`）与阙文标记 `[[]]`；
   - 存储路径：`book-text/Book/.../original/`。
2. **通行繁体（`traditional`）**：
   - 通过 `norm` 规范映射表，将刻本异体字转为现代通行的正规繁体字（`𢰅` $\rightarrow$ `撰`）；
   - 保留文言典雅繁体版面，降低阅读生僻门槛。
3. **现代简体（`simplified`）**：
   - 经由 `opencc-js`（`t2cn` 词库）统一繁简转换；
   - 专名号与篇名号保持完好，服务现代大众阅读。
